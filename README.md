# toon-cli

**Convert any prompt or structured file to compact `.toon` format — locally, securely, fast.**

`.toon` is a token-optimized, human-readable document format designed for LLM contexts. It uses `@directive value` syntax to represent structured information in ~50% fewer tokens than equivalent JSON.

---

## Install

```bash
pip install toon-cli
```

Or from source:

```bash
git clone https://github.com/yourusername/prompt-to-toon-cli
cd prompt-to-toon-cli
pip install -e .
```

**Requirements:** Python 3.10+

---

## Quick Start

```bash
# Convert a file
toon spec.json

# Inline prompt
toon --text "Create a FastAPI auth service with JWT and OAuth2"

# From stdin
cat spec.yaml | toon --stdin

# With options
toon spec.md --output result.toon --pretty --validate

# Validate an existing .toon file
toon validate result.toon
```

## CLI Reference

```
toon [FILE] [OPTIONS]
toon validate FILE
```

| Option            | Short | Description                                |
|-------------------|-------|--------------------------------------------|
| `--text TEXT`     | `-t`  | Inline natural-language prompt             |
| `--stdin`         |       | Read from stdin                            |
| `--output PATH`   | `-o`  | Output path (default: `<input>.toon`)      |
| `--validate`      | `-v`  | Validate output and print report           |
| `--pretty`        | `-p`  | Add comments and blank lines               |
| `--compact`       | `-c`  | Minimal output, no spacing                 |
| `--stdout`        |       | Print to stdout instead of saving          |

## Output Format

`.toon` uses a simple `@directive value` syntax:

```toon
# Generated by toon-cli
# source: json

@task auth_service
@desc Stateless JWT-based authentication and authorization service
@tags jwt oauth2 refresh_tokens
@type backend_service

@dependencies python-jose passlib sqlalchemy
@security bcrypt_hashing token_blacklist rate_limiting
```

**Why .toon?**
- ~50% fewer tokens than equivalent JSON in LLM contexts
- Human-readable and editable
- Deterministic, lossless round-trips
- No schema required

See [toonformat.dev](https://toonformat.dev) for the full spec.

## Examples

### JSON → .toon

```bash
toon examples/auth_service.json --pretty
```

Input (`auth_service.json`):
```json
{
  "task": "auth_service",
  "stack": "fastapi",
  "features": ["jwt", "oauth2", "refresh_tokens"]
}
```

Output (`auth_service.toon`):
```toon
@task auth_service
@tags jwt oauth2 refresh_tokens
```

### Natural language → .toon

```bash
toon --text "Build a recommendation engine using collaborative filtering and Redis caching"
```

Output (`output.toon`):
```toon
@task build_a_recommendation_engine_using_collaborative_filtering_and
@desc Build a recommendation engine using collaborative filtering and Redis caching
@tags Redis
```

### Validate

```bash
toon validate output.toon
# ✓ valid — 3 directives
```

## Architecture

```
input
  └─ parse_file / parse_text / parse_stdin   (src/parser/input_parser.py)
       └─ ParsedInput (raw, fmt, data)
            └─ normalize()                   (src/parser/normalizer.py)
                 └─ SemanticDoc
                      └─ generate()          (src/generator/toon_generator.py)
                           └─ .toon string
                                └─ validate() (src/validator/toon_validator.py)
                                     └─ write() (src/writer/file_writer.py)
                                          └─ .toon file
```

**Design principles:**
- No agents, no orchestration — a simple linear pipeline
- No network calls — 100% local execution
- Minimal dependencies: `typer`, `pydantic`, `PyYAML`
- Atomic file writes (temp → rename)
- Input sanitization at every boundary
