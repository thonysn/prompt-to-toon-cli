# Recommendation Engine

A collaborative filtering recommendation engine with Redis caching.

## Stack
- Python 3.12
- FastAPI
- Redis
- PostgreSQL

## Features
- collaborative_filtering
- content_based_filtering
- real_time_personalization
- ab_testing_support
- cold_start_handling

## Performance
Target latency under 50ms at p99 for 10k concurrent users.

## Deployment
- Docker
- Kubernetes
- Horizontal pod autoscaling
